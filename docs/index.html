Training-free scale-space transformers on Daubechies wavelets

ssmix replaces learned attention with exact multiscale operators: Daubechies wavelets of any order, a GPU-batched tight frame, and a cross-scale attention mixer in which every wavelet coefficient attends to its siblings, parent and children. Nothing is trained.

Try it in the browser: live demo on Hugging Face Spaces.

Requires Python ≥ 3.9, PyTorch ≥ 2.0, torchaudio, NumPy and mpmath.

Embed audio in three lines

from ssmix import AudioEmbedder

emb = AudioEmbedder()                                  # no weights to download
E = emb.embed(waves, sample_rate=44100, length=5.0)    # list of 1-D arrays -> (N, D) numpy

Inputs are resampled to 32 kHz. With length every clip is padded or cut to the same duration, so all embeddings share one dimension. Use the embeddings with any linear model, k-NN or clustering.

Use the mixers as layers

import torch
from ssmix import SWTCrossScaleMixer, ScaleSpaceMixer

x = torch.randn(8, 4096, 64)                           # (batch, tokens, channels)
mix = SWTCrossScaleMixer(order=4, heads=8, window=2, tau=0.1)
y = mix(x)                                             # same shape, cross-scale attention

frame = ScaleSpaceMixer(order=8, rule="identity")      # db8 tight frame
W = frame.analysis(x)                                  # (8, J+1, 4096, 64) scale-space coefficients
assert torch.allclose(frame(x), x, atol=1e-5)          # exact round trip

What is inside

ObjectRole
AudioEmbedderTraining-free audio transformer: log-mel → cross-scale mixer blocks → pooled scale-space readout.
SWTCrossScaleMixerCross-scale attention on the undecimated, delay-aligned Daubechies frame; shift-equivariant.
CrossScaleMixerThe same attention on the decimated orthonormal wavelet tree.
ScaleSpaceMixerFFT-batched Daubechies tight frame for any length, with parameter-free gate rules.
DWTPeriodic orthonormal DWT/IDWT, identical to PyWavelets periodization.
daubechiesDaubechies filters of any order, built from scratch by spectral factorisation.
