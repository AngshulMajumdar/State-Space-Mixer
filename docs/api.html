class AudioEmbedder

ssmix.AudioEmbedder(depth: int = 2, sample_rate: int = 32000, n_mels: int = 128, order: int = 4, heads: int = 16, window: int = 2, tau: float = 0.1, levels: Optional[int] = None, freq_order: int = 2, readout: Sequence[str] = ('bands', 'freq', 'stats', 'mixed', 'attn', 'env'))

Training-free audio transformer that maps waveforms to fixed-size embeddings.

Pipeline:
    log-mel spectrogram (25 ms window, 10 ms hop)  ->  per-clip normalisation
    depth x [ undecimated Daubechies scale space along time
              -> cross-scale attention (siblings, parent, children)
              -> exact tight-frame synthesis ]
    readout of every block, pooled over time.

The model has no learnable parameters and needs no training data.

Args:
    depth:       number of mixer blocks.
    sample_rate: rate the model operates at; `embed` resamples inputs to it.
    n_mels:      mel bands.
    order:       Daubechies order N of the time-axis frame (support 2N-1).
    heads:       attention heads (mel bands are split into `heads` groups).
    window:      sibling half-width k of the cross-scale neighbourhood.
    tau:         attention temperature.
    levels:      wavelet levels J (None: chosen from the clip length).
    freq_order:  Daubechies order of the spectral (mel-axis) scale space used in the readout.
    readout:     subset of ("bands", "bstd", "freq", "stats", "mixed", "attn", "astd", "env").

Readout terms (per block unless noted):
    bands  log mean_t |W_s| before mixing, per band and mel bin
    bstd   std_t log|W_s| before mixing
    freq   log mean_t |spectral scale-space band|, per band and mel bin
    stats  mean_t and std_t of the normalised log-mel state
    mixed  log mean_t |W'_s| after mixing
    attn   mean_t cross-scale attention weight, per band, link and head
    astd   std_t of the cross-scale attention weights
    env    mean log-mel spectrum before normalisation (once, appended last)

Example:
    >>> emb = AudioEmbedder()
    >>> E = emb.embed([wave_a, wave_b], sample_rate=44100)   # (2, D) numpy array

Embed a batch of equal-length waveforms.

Embedding dimension for clips of `num_samples` samples at `sample_rate`.

embed(self, audio: Union[numpy.ndarray, torch.Tensor, Iterable[Union[numpy.ndarray, torch.Tensor]]], sample_rate: Optional[int] = None, batch_size: int = 16, length: Optional[float] = None) -> numpy.ndarray

Embed one clip, a batch, or a list of clips of any lengths.

Args:
    audio:       1-D waveform, (B, N) array/tensor, or a list of 1-D waveforms (mono, [-1, 1]).
    sample_rate: rate of `audio`; resampled to `self.sample_rate` when different.
    batch_size:  clips per forward pass.
    length:      if given, every clip is zero-padded or cut to this many seconds, so all

                 can have different embedding sizes (the number of wavelet levels
                 follows the clip length).
Returns:
    (B, D) float32 numpy array (rows in input order).

class SWTCrossScaleMixer

ssmix.SWTCrossScaleMixer(order=4, levels=None, heads=8, window=1, tau=0.1, scales=(-1, 0, 1), pad='reflect')

Cross-scale attention on the undecimated, delay-aligned Daubechies tight frame.

Every band s = 0..J (J details + approximation) has a token at every instant t.
Token (s, t) attends to the bands s-1, s, s+1 at instants t + o * 2^{lev(s')},
|o| <= k (lev = dyadic level of the key band), i.e. its dyadic siblings, parent
and children on the same grid as the decimated tree, without decimation, so the
operator is shift-equivariant. Weights: parameter-free cosine attention per head;
values are the raw coefficients. tau -> 0 is the exact identity (self has
cosine 1); synthesis is the tight-frame adjoint.  Input/output (B, T, C).

coefficients(self, x)

(B, T, C) -> padded coefficients Wp (B, S, C, n), plan, T.

synthesize(self, Wp, plan, T)

Padded coefficients (B, S, C, n) -> (B, T, C) by the tight-frame adjoint (exact inverse).

links(self, S)

Key list of every band: [(key band, time shift in samples)], self first.

mix(self, Wp)

One synchronous cross-scale attention update on padded coefficients (B, S, C, n).

Layout (B, S, H, n, D) keeps each head's channels contiguous; tokens are normalised once
and keys are never materialised, so memory is O(B S C n) and the work is
O(B S C n (2k+1) |scales|) multiply-adds.

forward(self, x)

(B, T, C) -> (B, T, C): analysis, one cross-scale attention update, synthesis.

class CrossScaleMixer

ssmix.CrossScaleMixer(order=4, levels: Optional[int] = None, max_levels=8, heads=1, window=2, tau=0.1, parent=True, children=True, pad='reflect')

Parameter-free cross-scale attention token mixer. Input/output (B, T, C).

Args:
    order:  Daubechies order N (support 2N-1).
    levels: J (None -> as many as the padded length allows, capped at max_levels).
    heads:  channel groups with independent attention.
    window: sibling half-width k.
    tau:    cosine-attention temperature (tau -> 0 is the identity).
    parent / children: include those links.

coefficients(self, x)

(B, T, C) -> ([D_1..D_J], A_J) each (B, C, N/2^s), plus padding info.

mix(self, ds, a)

One synchronous cross-scale attention update. Bands: (B, C, n_s).

forward(self, x)

(B, T, C) -> (B, T, C): DWT, one cross-scale attention update, inverse DWT.

class ScaleSpaceMixer

ssmix.ScaleSpaceMixer(order: Optional[int] = 4, support: Optional[int] = None, levels: Optional[int] = None, heads: int = 1, rule: str = 'attention', tau: float = 1.0, kappa: float = 1.0, pad: str = 'reflect', delay_compensation: bool = True, fast_fft: bool = True, pad_tol: float = 1e-08, eps: float = 1e-12)

Undecimated Daubechies tight frame (FFT-batched, any T) with parameter-free gate rules.

Args:
    order:     Daubechies order N (N vanishing moments, support 2N-1).
    support:   alternative to `order`; must be odd (= 2N-1).
    levels:    number of detail levels J (None -> as many as fit T, max 10).
    heads:     channel groups sharing one scale-attention pattern.
    rule:      'attention' | 'shrink' | 'identity'.
    tau:       attention temperature.
    kappa:     energy-smoothing width, in units of each band's dyadic scale.
    pad:       'reflect' (no wrap-around artefacts) or 'circular'.
    delay_compensation: align bands in time (pure phase; keeps PR).
    fast_fft:  extend padded length to a 5-smooth FFT size.
    pad_tol:   reflect padding covers all but this fraction of every band's
               impulse-response energy (PR is exact for any value).
Input/Output: (B, T, C).

num_levels(self, T: int) -> int

Detail levels J used for length T (the `levels` argument, or as many as fit, at most 10).

analysis(self, x: torch.Tensor) -> torch.Tensor

(B, T, C) -> (B, J+1, T, C) band coefficients (on the unpadded grid).

synthesis(self, W: torch.Tensor) -> torch.Tensor

Adjoint of `analysis` in circular mode; (B, J+1, T, C) -> (B, T, C).
(In reflect mode use forward(); W here lives on the unpadded grid.)

gates(self, x: torch.Tensor) -> torch.Tensor

Gate field (B, J+1, T, C) the mixer applies to x (for inspection).

forward(self, x: torch.Tensor) -> torch.Tensor

(B, T, C) -> (B, T, C): analysis, gate rule, synthesis (rule='identity' returns x).

class DWT

ssmix.DWT(order: int = 4)

Periodic orthonormal DWT along the last axis of (..., N), N % 2^J == 0.

max_levels(self, N: int) -> int

Largest J with N divisible by 2^J and the coarsest band no shorter than the filter.

forward(self, x: torch.Tensor, J: int) -> Tuple[List[torch.Tensor], torch.Tensor]

J-level DWT of (..., N). Returns ([D_1, ..., D_J], A_J), D_j of length N / 2^j.
Identical to PyWavelets wavedec(x, f"db{order}", mode="periodization", level=J).

inverse(self, ds: List[torch.Tensor], a: torch.Tensor) -> torch.Tensor

Exact inverse (adjoint) of forward: ([D_1, ..., D_J], A_J) -> (..., N).

function daubechies

ssmix.daubechies(order: int)

(h, g): orthonormal Daubechies lowpass and highpass filters of the given order (2*order taps).
Identical to PyWavelets dbN rec_lo / rec_hi.

function daubechies_lowpass

ssmix.daubechies_lowpass(order: int) -> numpy.ndarray

Orthonormal lowpass h (sum h = sqrt 2, sum h^2 = 1), length 2*order.

function qmf_highpass

ssmix.qmf_highpass(h: numpy.ndarray) -> numpy.ndarray

g[n] = (-1)^n h[L-1-n]  (PyWavelets rec_hi convention).
